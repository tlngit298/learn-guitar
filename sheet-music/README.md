# Giai điệu chấm dôi

Đây là bản ký âm chuẩn, không có tablature. Mở file `dau-cham-doi-melody.musicxml` bằng MuseScore, Dorico, Sibelius hoặc phần mềm hỗ trợ MusicXML để xem/in khuông nhạc.

File `.ly` là nguồn LilyPond tương đương nếu bạn dùng LilyPond để xuất PDF.

## Cách luyện

1. Đặt metronome ở `♩ = 60`, đọc nhịp 4/4.
2. Đọc tên nốt và đếm thành tiếng: nốt đen chấm dôi kéo dài `1 & 2`, nốt móc đơn tiếp theo rơi vào `&` của phách 2.
3. Hát giai điệu trước, sau đó chơi trên một dây bất kỳ bằng âm thanh sạch.
4. Khi chắc nhịp, tăng lên 66 rồi 72 BPM. Nếu bị dồn hoặc hụt, quay lại tempo trước.
5. Ghi âm một lần đọc nốt và một lần chơi giai điệu; nghe lại để kiểm tra trường độ.
